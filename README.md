# 💳 Banking Database System

##  Description
A relational database system designed to manage banking operations such as customer accounts and financial transactions using SQL.

##  Features
- Customer management
- Account management
- Deposit and withdrawal operations
- Transaction tracking
- Balance analysis using SQL queries

##  Technologies Used
- SQL (MySQL)

##  Database Schema
- Customers
- Accounts
- Transactions

##  Key Concepts Used
- Joins
- Aggregate Functions (SUM, COUNT)
- Group By
- Constraints (Primary Key, Foreign Key, Unique)
- Relational Database Design

##  How to Run

1. Open MySQL / SQL environment
2. Run:
   - schema.sql
   - data.sql
   - queries.sql
